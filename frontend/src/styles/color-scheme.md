# 配色方案文档 - 60-30-10 法则

## 设计理念

- **风格定位**：低饱和度、治愈系、安全感
- **灵感来源**：米白色背景、马卡龙绿、柔和暖木色

---

## 颜色分配

### 主色（60%）- 大面积背景

**目标**：柔和护眼、不刺眼、建立主体视觉基调

| 模式  | 颜色值  | RGB         | 说明                             |
| ----- | ------- | ----------- | -------------------------------- |
| Light | #F5F2ED | 245,242,237 | 米白色背景，极低饱和度，温暖护眼 |
| Dark  | #1A1815 | 26,24,21    | 温暖深色背景，避免纯黑刺眼       |

---

## CSS变量映射

### Light 模式

```css
/* 主色 - 背景 */
--bg: #f5f2ed --bg-elevated: #fdfbf8 /* 辅助色 - 卡片与区块 */ --surface: rgba(255, 255, 255, 0.92)
	--surface-strong: #fdfbf8 --surface-hover: #f0ebe3 --surface-soft: rgba(111, 185, 105, 0.06)
	/* 边框 */ --border: rgba(232, 228, 220, 0.6) --border-strong: rgba(212, 165, 116, 0.3)
	/* 强调色 */ --accent: #6fb969 --accent-strong: #5eccc4 --accent-soft: rgba(111, 185, 105, 0.12)
	/* 状态色 */ --success: #6fb969 --warning: #d8937d --danger: #d97676 --info: #8fb1d5 /* 文本 */
	--text-primary: #2a2420 --text-muted: #6b6560 --text-placeholder: #9c9691;
```

```css
/* 主色 - 背景 */

```

## 使用指南

1. **主色应用（60%）**
    - 整体页面背景色
    - 大面积底色区域

2. **辅助色应用（30%）**
    - 卡片/容器背景
    - 边框/分割线
    - 标签/徽章背景
    - 侧边栏背景

3. **强调色应用（10%）**
    - Primary Button（主操作）
    - 链接
    - 高亮文本
    - 图标（重要）
    - 进度条

---

## 无障碍性考虑

- 文本对比度满足 WCAG AA 标准（最小4.5:1）
- 低饱和度设计减少长时间观看疲劳
- 色弱人士可以通过形状/图标进行辅助识别
